## Befunde

### HIGH-1 — `targets` deckt nur AGENTS.md; harness/README.md-Sensors-Tabelle fällt aus der Prüfung
`doc-tables: [AGENTS.md]` ist unvollständig: `gate-consistency.sh` scannt **AGENTS.md UND harness/README.md**
(Skript Z. 30); `harness/README.md` §Sensors (Z. 69–84) ist eine zweite `make X`-Tabelle. Der geprüfte Korpus
schrumpft von zwei Honesty-Dokumenten auf eines — die »verhaltens-erhaltend«-Behauptung ist falsch; ein
Phantom in README bliebe ungefangen. **Fix:** `doc-tables: [AGENTS.md, harness/README.md]` (Liste, Handbuch §5).
→ **eingearbeitet** (DoD A).

### HIGH-2 — AGENTS.md §3-»Geplant«-Tabelle wirft `gate-phantom` (targets kennt keine Sektions-Marker)
`gate-consistency.sh` unterdrückt Geplant-Zeilen via `awk`-Marker; `targets` liest **jede** Tabellenzeile
(Handbuch §6). AGENTS.md §3 (Z. 170–174) behauptet `make coverage-gate-critical`/`make ci`/`make fullbuild` —
**nicht** real ⇒ **`gate-phantom ×3`**, blockiert `make gates grün`. `exempt-targets` hilft **nicht** (nur
`gate-undocumented`-Richtung). **Fix:** Geplant-`make X` aus der Tabellen-Form nehmen; Baseline-Lauf vor Retire.
→ **eingearbeitet** (DoD A neuer Punkt).

### HIGH-3 — Löschen der Skripte bricht `docs-check`; kein Tombstone/Purge-Plan
`harness/conventions.md` Z. 444 + Z. 478 verlinken `tools/gate-consistency.sh` → `target-missing` (`links`)
+ `codepath-missing` (`codepaths`, roots enthält `harness`). Auch der Plan selbst nennt die Tools als
Inline-Code → `codepath-missing` nach Retire. slice-033 löste exakt das per `ignore-refs`-Tombstone. **Fix:**
conventions.md Z. 444/478 purgen; `.d-check.yml codepaths.ignore-refs += tools/gate-consistency.sh, tools/idlink.py`.
→ **eingearbeitet** (DoD C neuer Punkt + Plan-Tabelle).

### MED-1 — idlink.py hat **keine** Anker-Hebung; Rest-Risiko #3 war ein Phantom
Am Quelltext verifiziert: `idlink.py` schreibt **nie** `<a id=…>` (Headings verbatim); die `HTML_ID`-Regex

`--repair` (Handbuch §4.10, nur nackte Prosa) **vollständig** gedeckt. Der Plan bucht Aufwand auf eine
**nicht existierende** Funktion. Die slice-018c-Anker existieren, wurden aber nicht von idlink.py erzeugt.
**Fix:** Rest-Risiko #3 streichen; Retire vereinfacht sich. → **eingearbeitet** (DoD B + Rest-Risiko #3
durchgestrichen).
